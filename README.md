# SYNAPS México · Guía y FAQ

Portal de capacitación y preguntas frecuentes de SYNAPS para el equipo de Webedia México.

Este repositorio solo publica la página en GitHub Pages. La fuente es `Synaps_MX/pa_webapp/static/index.html`
(la misma landing de la webapp de PythonAnywhere); se regenera con `python3 build_github_pages.py`.
